# Smart City Traffic Intelligence: From Data Analytics to AI-Powered Mobility



## Capstone Project



This repository contains the capstone project for the NUS School of Computing AI, Machine Learning and Data Science programme.



The project develops an end-to-end Smart City Traffic Intelligence solution by integrating data analytics, Python programming, machine learning, deep learning, explainable AI, recommendation systems, and MLOps.



## Project Structure



The project is organised into three main parts:



### Part 1 – Data Analytics

`part1\_data\_analytics/`



This section focuses on:

- SQL-based data analysis

- Descriptive statistics and correlation analysis

- Probability and conditional probability

- Power BI dashboard and data preparation

- Integration and interpretation of analytical findings



### Part 2 – Python Programming

`part2\_python/`



This section focuses on:

- Data pipeline construction and cleaning

- Schema validation and exception handling

- Feature engineering using NumPy and Pandas

- Data visualisation

- Mini-application development

- Logging and reproducibility



### Part 3 – Machine Learning and AI

`part3\_machine\_learning/`



This section focuses on:

- Supervised machine learning

- Unsupervised machine learning

- Deep learning

- Explainable AI using SHAP/LIME

- Advanced AI techniques

- Recommendation systems

- MLOps and deployment simulation

- Responsible and sustainable AI



## Project Objective



The objective of this project is to transform traffic data into actionable insights and develop an integrated AI-powered mobility solution.



The project demonstrates the complete workflow from data preparation and analysis to machine learning, explainability, recommendations, deployment simulation, monitoring, and responsible AI evaluation.
